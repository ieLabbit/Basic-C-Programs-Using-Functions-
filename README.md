# C Programming Practice

Welcome to my C Programming Practice repository!

This repository contains a collection of C programs and practice exercises that I have developed while learning the fundamentals of C programming.

My objective is to understand programming concepts, improve my logical thinking, and document my learning progress through practical coding exercises.

The programs in this repository cover various fundamental concepts of C programming.

- Switch Statements
- For, While and Do-While Loops
- Nested Loops
- User-Defined Functions
- Mathematical Operations
- Number-Based Programs

- Mathematical Calculations

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Compile the source code using GCC.
4. Run the generated executable.

Compilation command:

`gcc main.c -o main -lm`

Run on Windows:

`main.exe`
